# 맥에서 시작하기

현재 파일은 완성된 `.app` 설치 프로그램이 아니라 **소스 코드**입니다. 이전 소스의 Intel iMac Pro / macOS Monterey 12.7.6 웹 앱 빌드는 확인됐습니다. **이번 수정본과 맥 AI 준비 도구의 네이티브 실행 검증은 남아 있습니다.** 빌드 오류가 나오면 멈추고 오류 내용을 확인해야 합니다.

## 1. 파일 받기

이 작업 브랜치의 GitHub 화면에서 초록색 **Code → Download ZIP**을 누릅니다. 다운로드한 ZIP을 더블클릭해 압축을 풉니다. 기본 브랜치 대신 `apps/filmcraft-shorts`가 포함된 작업 브랜치를 내려받아야 합니다.

## 2. 압축을 푼 폴더에서 터미널 열기

1. **⌘ + 스페이스바 → 터미널 → Enter**로 터미널을 엽니다.
2. 터미널에 `cd `를 입력합니다. `cd` 뒤에 공백 한 칸을 넣고, 아직 Enter를 누르지 않습니다.
3. Finder에서 압축을 푼 최상위 폴더를 터미널 창으로 끌어 놓습니다.
4. 폴더 경로가 입력되면 Enter를 누릅니다.
5. `ls Cargo.toml`을 실행했을 때 `Cargo.toml`이 표시되면 올바른 폴더입니다.

## 3. 맥용 실행 파일 만들기

Xcode Command Line Tools와 Rust/Cargo가 설치되어 있어야 합니다. 저장소의 최소 Rust 버전은 1.95입니다. 아래 명령은 소스 코드에서 맥용 프로그램을 만듭니다. 첫 실행에는 의존성을 다운로드하고 빌드하므로 시간이 걸립니다.

```sh
cargo build --locked -p filmcraft-shorts --features whisper -j 4
```

실패하면 뒤의 실행 명령을 입력하지 말고 오류를 확인합니다. 이 코드가 Monterey에서 작동한다고 아직 보장할 수는 없습니다.

## 4. 브라우저 화면 열기

빌드가 성공한 뒤 같은 터미널에서 실행합니다.

```sh
./target/debug/filmcraft-shorts-web
```

터미널을 열어 둔 상태에서 Safari 또는 Chrome의 주소창에 `http://127.0.0.1:8787`을 입력합니다. 이 주소는 **프로그램을 실행한 맥 안에서만** 작동합니다. 서버를 종료하려면 터미널에서 **Control + C**를 누릅니다.

웹에서 촬영본 업로드, 카메라/녹음 역할과 촬영 그룹, 편집 지시를 준비할 수 있습니다. 실제 자동 편집을 시작하려면 아래 AI 준비가 추가로 필요합니다.

## 5. 발언 선택용 로컬 AI 준비

웹 화면만 실행하면 ‘로컬 AI 준비 필요’가 나오는 것이 정상입니다. 발언을 고르는 AI 서버는 별도로 실행해야 합니다. API 키나 외부 AI 계정은 필요하지 않습니다.

웹 서버 터미널은 열어 두고 **⌘ + N으로 새 터미널 창**을 엽니다. 2번처럼 같은 프로젝트 폴더로 이동한 뒤 다음 명령을 실행합니다.

```sh
bash apps/filmcraft-shorts/scripts/setup-mac-ai.sh
```

이 도구는 Homebrew 없이 공식 CMake 3.31.8(고정 SHA-256 확인), llama.cpp b11669(고정 Git 커밋 확인)를 내려받고 CPU용 실행기를 빌드합니다. 이후 공식 Qwen3-4B-Instruct-2507 Q4_K_M 모델 약 3GB를 다운로드해 공식 메타데이터의 SHA-256과 크기로 검증합니다. 첫 설치에는 여유 공간 약 6GB 이상과 인터넷 연결이 필요합니다. 영상·대본은 업로드하지 않습니다. 기존 사용자 파일은 덮어쓰지 않고, 충돌하면 오류로 중단합니다.

다운로드·빌드가 끝나면 같은 창에서 실행하세요.

```sh
bash apps/filmcraft-shorts/scripts/start-local-model.sh
```

모델 로딩이 끝날 때까지 기다리세요. 이 창도 켜 두고 브라우저의 **실행 환경 → 준비 상태 다시 확인**을 누릅니다. `interview-local` 모델이 실제로 서비스되는지 확인한 뒤 편집 버튼이 활성화됩니다. CPU로 실행하므로 긴 대본 처리는 느릴 수 있습니다. 다음 사용부터는 준비 스크립트 없이 시작 명령만 실행하면 됩니다.

설치 위치는 `~/Library/Application Support/FilmcraftShorts/ai`입니다. `FILMCRAFT_AI_DIR`를 설정하면 준비·시작 명령 양쪽에 같은 경로를 사용하세요. 음성 인식용 Whisper 가중치는 첫 편집 때 별도로 내려받습니다. 다운로드 실패·TLS 오류·빌드 오류는 마지막 오류 내용을 확인하고 진행을 멈추세요. 인증서 검증을 끄지 마세요.

**검증 범위:** 이 맥 준비 도구는 Linux에서 구문과 경로·다운로드 검증 로직을 검사했습니다. Intel Monterey에서 CMake/llama.cpp 네이티브 빌드를 실행하거나 실제 한국어 인터뷰 품질을 확인한 것은 아닙니다. 웹 앱의 네이티브 빌드는 사용자 맥에서 성공한 상태입니다.

## 6. 소탐대실 자막 스타일

**편집 방향 → 자막 디자인 → 소탐대실**을 선택합니다. 촬영본 목록의 **자막 화자**에서 각 오디오 소스가 게스트인지 제작진인지 지정합니다. 선택된 마이크에 따라 게스트는 노랑, 제작진은 청록, 제목은 청록으로 출력됩니다. 하나의 녹음에 두 화자가 섞여 있으면 그 파일의 지정이 적용되며, 목소리만으로 역할을 검증하지는 않습니다.

PSD에서 읽은 색상·글꼴 이름·위치·크기로 만든 프리셋이며, 임의 PSD를 웹에 올려 해석하는 기능은 아닙니다. 제목은 전체 영상 동안 상단에 유지되고 긴 제목은 두 줄로 나눕니다. 말자막은 원문 단어를 사용하고 컷마다 화자 스타일을 분리합니다. 편집 프로젝트에는 세 개의 표시 트랙과, SRT 내보내기용 통합 대사 트랙(표시 꺼짐)이 있습니다. SRT는 대사·시간만 포함하며 색상·글꼴은 MP4와 편집 프로젝트에 반영됩니다.

PSD의 `SDCheongRyu`, `GangwonEduAll-OTFBold` 글꼴은 파일에 포함하지 않았습니다. 사용 권한이 있는 글꼴을 맥의 서체 관리자에서 설치한 뒤 웹 서버를 다시 시작하세요. **제목 글꼴 / 말자막 글꼴** 입력 목록에서 실제 설치된 패밀리 이름을 선택할 수 있습니다. PSD의 PostScript 이름과 설치된 패밀리 이름이 다를 수 있습니다. 찾지 못한 글꼴은 경고하고 설치된 한국어 지원 대체 글꼴로 출력합니다. 대사를 표시할 글꼴 자체가 없으면 깨진 글자 영상을 만들지 않고 오류로 중단합니다. 합성 스타일 렌더링 검사는 배포 가능한 Inter/영문으로 수행했고, 사용자 PSD의 실제 글꼴을 사용한 한국어 모양은 아직 검증하지 않았습니다. 원본 PSD의 자간과 정확한 글리프 위치까지 동일한 재현은 아니므로 짧은 결과로 확인하세요.
