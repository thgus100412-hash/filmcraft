실행 준비

처음 사용하는 경우: 모델 준비 안내

웹 화면과 별도로 발언 선택용 AI 서버를 실행해야 합니다. 처음 한 번은 인터넷에서 실행 도구와 모델(약 3GB)을 내려받습니다. 영상과 대본은 전송하지 않습니다.

맥: 프로젝트 폴더에서 새 터미널을 열고 다음 명령을 실행하세요. Intel 맥은 CPU로 처리합니다. 

bash apps/filmcraft-shorts/scripts/setup-mac-ai.sh

준비가 끝나면 아래 명령을 실행하고 이 터미널도 켜 두세요.

bash apps/filmcraft-shorts/scripts/start-local-model.sh

모델 로딩이 끝난 뒤 ‘준비 상태 다시 확인’을 누르세요. 오류가 나오면 마지막 오류 내용을 확인하세요. macOS Monterey에서 설치 도구와 모델을 직접 실행한 검증은 아직 남아 있습니다.

Linux 클라우드 전용 도구:

bash apps/filmcraft-shorts/scripts/setup-cloud.sh
python3 apps/filmcraft-shorts/scripts/fetch-local-model.py
bash apps/filmcraft-shorts/scripts/start-local-model.sh
현재 버전에서 알아두세요

화자와 마이크는 대본과 입력한 설명을 바탕으로 선택합니다. 얼굴 추적, 목소리 지문 매칭, 장시간 촬영의 시계 드리프트 보정은 아직 지원하지 않습니다. 실제 인터뷰의 인식·편집 품질은 결과에서 확인해 주세요.
